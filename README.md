# Bakaiti website

Static site for the Bakaiti sticker app, served with GitHub Pages at
https://tniraj7.github.io/bakaiti-site/

Pages: Home, Support, Privacy Policy, Terms of Use, Contact, Copyright and content reports.

The source of these files is the `web/` folder of the Bakaiti app repository. This repo is a
published copy: change the files there, then copy them here (the 404 page here uses the
`/bakaiti-site/` path prefix).

`app-ads.txt` for AdMob is not in this repo. It is served from the root of
https://tniraj7.github.io/ (the `tniraj7.github.io` repo).
